# Community Skills Examples for Antigravity CLI

This directory contains portable, self-contained agent skills that can be installed into `~/.agents/skills/<skill-name>/`:

1. **[`local-llm-web-search`](local-llm-web-search/SKILL.md)**: Zero-API-key live web search, parallel page extraction, and local LLM synthesis via Ollama (`127.0.0.1:11434`) or any OpenAI-compatible local server.
2. **[`linux-usb-xhci-diagnostics`](linux-usb-xhci-diagnostics/SKILL.md)**: Kernel-register-first Linux USB-C, xHCI link lane (`portli`), USB 2.0 Single-TT vs. Multi-TT hub collision, and DisplayPort diagnostic workflow.
3. **[`headless-vector-pdf`](headless-vector-pdf/SKILL.md)**: Publication-grade Markdown-to-Print-CSS vector PDF and Graphviz SVG-to-PNG compilation using headless Chromium/Chrome without root privileges.
