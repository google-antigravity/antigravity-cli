# Antigravity CLI

**Языки / Languages:** [English](./README.md) · [中文](./README-ZH.md) · [Español](./README-ES.md) · [Français](./README-FR.md) · [Português](./README-PT.md) · [Русский](./README-RU.md) · [Deutsch](./README-DE.md)

Antigravity CLI понимает вашу кодовую базу, вносит правки с вашего разрешения и выполняет команды — прямо из терминала.

- **Официальная документация**: [antigravity.google/docs/cli-overview](https://antigravity.google/docs/cli-overview)
- **Официальный сайт**: [antigravity.google/product/antigravity-cli](https://antigravity.google/product/antigravity-cli)

![Antigravity CLI Demo](agy-cli-demo.gif)

---

Antigravity CLI переносит ключевые возможности Antigravity 2.0 (многошаговое рассуждение, редактирование нескольких файлов, вызов инструментов и постоянная история) прямо в терминал. Оптимизирован для клавиатурных рабочих процессов и удалённых SSH-сессий с минимальной нагрузкой на ресурсы.

---

## Краткий обзор возможностей

| Возможность | Antigravity CLI | Antigravity 2.0 |
| :--- | :--- | :--- |
| **Основной фокус** | Скорость, эффективность с клавиатуры, низкая нагрузка | Полнота, визуальная оркестрация, управление проектами |
| **Интерфейс** | Терминальный пользовательский интерфейс (TUI) | Полноценное GUI-приложение |
| **Рабочие процессы** | SSH/удалённые сессии, приоритет клавиатуры | Локальные рабочие пространства, интенсивная оркестрация |
| **Движок агентов** | Общий центральный движок агентов | Общий центральный движок агентов |

---

## Интеграция

- **Общий движок агентов**: Оба интерфейса работают на одном центральном движке агентов. Улучшения автоматически применяются к обоим.
- **Общие настройки**: Предпочтения и разрешения синхронизируются в обе стороны.
- **Экспорт сессий**: Экспортируйте терминальные сессии в GUI Antigravity 2.0 для продолжения работы.

## Установка

### macOS / Linux
```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

### Windows PowerShell
```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

### Windows CMD
```cmd
curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd
```

## Аутентификация

CLI аутентифицируется через системное хранилище ключей, с резервным вариантом Google Sign-In при отсутствии активной сессии.

- **Локально**: Автоматически открывает браузер по умолчанию.
- **Удалённо / SSH**: Определяет SSH-сессии и выводит URL авторизации для завершения входа локально.
- **Выход**: Выполните `/logout` для очистки сохранённых учётных данных.

> [!NOTE]
> Для корпоративного доступа подключите проект GCP при onboarding. Подробности на странице Enterprise.
